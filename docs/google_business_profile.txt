<비즈니스 프로필 등록>
url : https://business.google.com/kr/business-profile/

1. 비즈니스프로필 시작
설명 : 파란색 '지금 시작하기' 버튼 누르기

2. 비즈니스 이름 작성
설명 : '비즈니스 이름*' 이라고 적혀있는 박스 안에 가게 이름을 작성한 후 파란색 '계속' 버튼 누르기

3. 업종 선택
설명 : 온라인 소매업/지역상점/서비스업 중에 모두 선택해주세요

4. 비즈니스 카테고리 입력
설명 : 네모박스 안에 비즈니스 카테고리를 작성해주세요

5. 주소 입력
설명 : 고객이 방문할 수 있는 실제 주소를 작성해주세요

6. 업체 확인
설명 : 이미 같은 이름으로 등록되어있는 프로필이 있다면 확인해주세요. 일치하는지/일치하지 않은지 선택한 후 파란색 '다음' 버튼을 눌러주세요

7. 업체 위치 선택
설명 : 지도 위에서 정확한 위치에 빨간색 아이콘을 올려놓으세요

8. 전화번호 및 세부사항
설명 : 고객에게 표시할 연락처 세부정보를 입력하세요, 건너뛰어도 됩니다.

9. 비즈니스 등록 
설명 : 화면 설명을 읽고 관련한 뉴스나 프로그램 참여를 원한다면 체크박스에 체크하세요. 선택 후 파란색 '계속' 버튼을 누르세요


<프로필 맞춤 설정> - 건너뛰어도 됨
10. 인증
설명 : 전화번호를 입력하고 인증을 받으세요. 이 과정은 건너뛰어도 됩니다. 

11. 영업시간 추가
설명 : 영업시간을 선택하세요. 건너뛰어도 됩니다.

12. 
식당 : 식사 방식 추가(매장 내 식사, 테이크아웃, 드라이브스루 등등)

13. 가게 설명 추가
설명 : 네모 박스 안에 추가하고싶은 설명을 작성하세요

14. 오프라인 매장 사진 추가
설명 : 가게 사진을 업로드 하세요

15. 메뉴사진 업로드
설명 : 메뉴사진을 업로드 하세요

16. 요리사진 추가
설명 : 요리 사진을 업로드 하세요

17. 광고 크레딧
설명 : Google Ads로 비즈니스 광고를 시작할 수 있습니다.

18. 마지막
설명 : 판매자 인증이 완료되면 Google을 이용하는 고객들에게 보여집니다. 


<비즈니스 정보 수정>
1. 내 비즈니스 접속
설명 : 내 비즈니스 창 들어가기

2. 프로필 수정
- 프로필 수정 아이콘 클릭 -> 아래로 스크롤 
- 가게 카테고리, 설명, 개업일 등 수정가능

3. 연락처 수정
- 프로필 수정 화면에서 아래로 스크롤 하여 전화번호 칸 찾기
- 커서를 글씨에 올려놨을 때 뜨는 연필모양 아이콘 클릭
- 수정 내용 작성
- 파란색 '저장' 버튼 클릭

4. 메뉴 수정
- 프로필 수정 화면에서 아래로 스크롤 하여 '메뉴 또는 서비스 링크' 칸 찾기
- 커서를 글씨에 올려놨을 때 뜨는 연필모양 아이콘 클릭
- 수정 및 등록 내용 작성
- 파란색 '저장' 버튼 클릭

5. 영업시간 수정
- 프로필 수정 화면에서 아래로 스크롤 하여 '영업시간' 칸 찾기
- 커서를 글씨에 올려놨을 때 뜨는 연필모양 아이콘 클릭
- '영업 중(기본 영업시간 있음)' 선택
- 아래로 스크롤하여 요일별 휴무일 지정
- 요일별로 오른쪽에 뜨는 영업시작, 영업종료시간 설정
- 파란색 '저장' 버튼 클릭
